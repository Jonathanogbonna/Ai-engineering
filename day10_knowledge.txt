Retrieval-Augmented Generation (RAG) is a technique that combines information retrieval with language generation.

RAG helps AI systems answer questions using information from external documents.

Embeddings convert text into numerical representations that capture semantic meaning.

Semantic search compares embeddings to find information related to a user's question.

Cosine similarity measures how closely two embeddings are related.

Text chunking divides large documents into smaller sections so they can be searched more effectively.

Chunk overlap preserves context by repeating some text between neighbouring chunks.

A RAG system retrieves relevant document chunks and provides them to a language model as context.

Large Language Models use the retrieved context to generate answers.

Retrieving multiple relevant chunks can provide more useful context than retrieving only one chunk.
